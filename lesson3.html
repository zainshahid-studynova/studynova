Lesson 3: Introduction to CSS

What is CSS?

CSS stands for Cascading Style Sheets. It is used to style and design HTML webpages.

While HTML creates the structure of a webpage, CSS controls how that webpage looks.

Why is CSS Important?

CSS allows us to change colors, backgrounds, text sizes, spacing and many other visual properties of a webpage.

Changing Text Color

The CSS property called color is used to change the color of text.

p {
  color: blue;
}

Changing Background Color

The background-color property is used to change the background color of an element.

body {
  background-color: lightblue;
}

Changing Font Size

The font-size property is used to make text smaller or larger.

h1 {
  font-size: 32px;
}

What Did You Learn?

In this lesson, you learned what CSS is and how CSS can change text color, background color and font size.
