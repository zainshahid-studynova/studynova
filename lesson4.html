Lesson 4: CSS Layout

What is CSS Layout?

CSS layout is used to control the position, spacing and appearance of elements on a webpage. It helps us organize content neatly.

Margin

The margin property creates space outside an element.

margin: 20px;

Padding

The padding property creates space inside an element, between the content and its border.

padding: 20px;

Borders

The border property adds a border around an element.

border: 2px solid black;

Rounded Corners

The border-radius property makes the corners of an element rounded.

border-radius: 10px;

What Did You Learn?

In this lesson, you learned about CSS layout properties such as margin, padding, borders and rounded corners.
