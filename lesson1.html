Lesson 1: Introduction to HTML

What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

HTML tells the browser what content should appear on a webpage, such as headings, paragraphs, images, links and buttons.

Why is HTML Important?

HTML is one of the basic technologies used to create websites. It provides the structure of a webpage, while CSS is used for styling and JavaScript is used to add interactivity.

Basic HTML Example

<h1>Hello World</h1>

<p>This is my first webpage.</p>

What Did You Learn?

In this lesson, you learned what HTML is and how HTML is used to create the basic structure of a webpage.
