Lesson 5: Web Development Basics

What is Web Development?

Web development is the process of creating websites and web pages for the internet.

HTML and CSS are two important technologies used when learning the basics of web development.

HTML

HTML stands for HyperText Markup Language. It is used to create the structure of a webpage.

<h1>My Website</h1>

<p>Welcome to my website.</p>

CSS

CSS stands for Cascading Style Sheets. It is used to style and design webpages.

p {
  color: blue;
}

HTML and CSS Together

HTML provides the structure of a webpage, while CSS controls its appearance.

Together, HTML and CSS help us create attractive and organized webpages.

Important Concepts You Learned

You learned about HTML structure, HTML tags, CSS styling, colors, backgrounds, margin, padding, borders and rounded corners.
