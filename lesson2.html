Lesson 2: Basic HTML Tags

What are HTML Tags?

HTML tags are used to tell the browser how different parts of a webpage should be structured.

Most HTML elements have an opening tag and a closing tag. The content is written between these tags.

Heading Tags

HTML provides heading tags from h1 to h6. The h1 tag is used for the main heading, while smaller headings can be created using h2, h3 and so on.

<h1>My Website</h1>

<h2>About Me</h2>

Paragraph Tag

The paragraph tag is written as <p>. It is used to display normal text in a webpage.

<p>Welcome to StudyNova!</p>

Link Tag

The anchor tag, written as <a>, is used to create links that allow users to move from one webpage to another.

<a href="course.html">Go to Course</a>

What Did You Learn?

In this lesson, you learned about HTML tags, heading tags, paragraph tags and links.
